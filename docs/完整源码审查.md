# system-actions 完整源码审查

2026-10-05，本轮逐文件读取自有生产 Kotlin、Swift、ArkTS、原生桥/导出与 manifest，并追踪公开调用链。审查覆盖 API 合同、状态归属、线程、最低系统、错误分类、取消/销毁与迟到回调；不以热点抽查替代完整文件清单。

## 结论与修改

OHOS SystemActions 新增剪贴板写入和当前 UIAbility 私有目录下普通文件分享；拒绝 URI、路径穿越和符号链接，使用系统 fileUri/ShareKit，不信任调用方自报 MIME。分享每次异步文件检查后复核 Pending 许可，取消/销毁阻止迟到面板。常亮复用既有 WindowPolicy controller/串行队列/lease，最后 owner 释放恢复初值；privacy 和常亮独立恢复，不改 privacy 时不调用需要 PRIVACY_WINDOW 的 API。Kuikly 新增三个对应入口，取消和销毁释放自身 lease，不覆盖其他 owner。false 的恢复失败保留 lease 供后续 false 重试，避免窗口仍常亮时误报受理。

iOS/HarmonyOS 无独立公开定位服务设置时继续返回 Unavailable；iOS 原生商店不支持时继续返回 Unavailable，录屏遮罩不承诺防截图。平台实际系统边界没有改成假成功。

## 最低系统与线程

Android：API24+；iOS：iOS14+；OHOS：实际 target/compatible API22。系统 UI、Window 与 UIKit presenter 使用现有 Main/UIAbility 边界，文件准备沿既有 IO；OHOS Window lease 使用 shared controller 的串行队列。

## 公开调用链

- SystemActions → Android Intent / 固定平台商店包名、UIKit openURL；应用设置和定位设置保持平台能力差异。
- AndroidFileActions / IosFileActions → 宿主私有文件、临时读取授权、统一 presenter 与 FileShareOutcome。
- SystemActionsModule → GycSystemActionsModule → SystemActions：requestId / Pending、原生商店回执、clipboard / share、watchdog / cancel / dispose。
- WindowPolicy → Android flag owner / UIKit window owner / OHOS shared controller：privacy、常亮和 fullscreen lease 串行恢复；SystemObservations 管理键盘与环境观察生命周期；Index 导出原生入口。
