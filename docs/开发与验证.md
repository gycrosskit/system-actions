## 本地行为检查

以下命令从仓库根目录执行。配置`ANDROID_HOME`与可运行Gradle的JDK；Kotlin/Native测试需要macOS、Xcode及iOS Simulator运行环境。Node测试转译真实ArkTS源码并使用受控SDK替身，`TYPESCRIPT_PATH`可指定已有TypeScript模块。

```sh
bash gradlew :system-actions-core:testDebugUnitTest :system-actions-core:jvmTest --max-workers=1
node ohos/tests/system-actions.test.cjs
node ohos/tests/system-actions-module.test.cjs
node ohos/tests/native-store.test.cjs
node ohos/tests/file-actions.test.cjs
node ohos/tests/keep-screen-module.test.cjs
node ohos/tests/system-observations.test.cjs
```

只运行受影响目标；需要确认本轮真实执行时加`--rerun-tasks`，不要把`UP-TO-DATE`算成新执行。平台测试结果XML位于`system-actions-core/build/test-results/`。这些测试不调用真实分享、认证、拨号或定位业务。

## Window 策略验证

```sh
node ohos/tests/window-policy.test.cjs
node ohos/tests/fullscreen-window.test.cjs
bash ios/Tests/run.sh
```

Swift runner编译生产策略源码及UIKit替身。真实SDK类型检查/构建与设备视觉验收分别记录；iOS静态截图不能被公开UIKit等价阻断。

## 原生产物与独立消费

HarmonyOS工具链需要DevEco SDK、ohpm与hvigorw。在`ohos/`目录执行：

```sh
ohpm install --all
hvigorw --mode module -p module=SystemActionsNative@default -p product=default assembleHar --no-daemon
```

安装与公开API消费工程按[接入指南](接入指南.md)和[README](../README.md)执行。构建/本地HAR消费不等于OHPM Registry或本版远程消费。Maven、Swift/Pod与HAR按各自版本验证。

## 结果与历史记录

本轮源码修复验证：`ohos/tests/keep-screen-module.test.cjs` 直接转译生产 ArkTS，增加两个 Ability、其中一个包含两个页面的 owner 场景，检查窗口解析、单页释放及另一 Ability 销毁互不影响。窗口 SDK 为替身；本轮实际 API22 生产 HAR 与临时本地 HAR consumer 均编译通过（各 30 tasks 全执行），consumer 显式传入 owner。尚未验收真实多 Ability 设备或公开发布渠道消费。
