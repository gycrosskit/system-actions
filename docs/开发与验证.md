# System Actions 开发与验证

消费者安装与调用见 [README](../README.md) 和[接入指南](接入指南.md)，历史验收见[验收记录](../verification/验收记录.md)。以下命令在仓库根目录执行。

## 最小验证

```sh
bash gradlew :system-actions-core:jvmTest :system-actions-core:testDebugUnitTest \
  :system-actions-core:compileKotlinIosSimulatorArm64 :system-actions-kuikly:compileKotlinOhosArm64
node ohos/tests/system-actions.test.cjs
node ohos/tests/system-actions-module.test.cjs
```

HAR 测试使用 TypeScript 转译器，可通过 `TYPESCRIPT_PATH` 指定模块。测试覆盖非法输入、等待受理、系统失败、设置包名、取消/销毁和迟到回执；mock 不能替代真实系统页面验收。

安装 DevEco SDK，并将 `tools/node/bin`、`tools/ohpm/bin`、`tools/hvigor/bin` 加入 `PATH` 后，在 `ohos` 中执行 `ohpm install --all` 与 `hvigorw assembleHar --no-daemon`。产物为 `system-actions-native/build/default/outputs/default/SystemActionsNative.har`。

## 独立消费与发布

```sh
bash gradlew -p verification-consumer compileDebugKotlinAndroid \
  compileKotlinIosArm64 compileKotlinIosX64 linkDebugFrameworkIosSimulatorArm64 compileKotlinOhosArm64
cd verification-ohos
ohpm install --all
hvigorw assembleHar --no-daemon
```

默认从 JitPack / OHPM Registry 获取远程版本，不引用本库源码。本地发布前执行 `bash gradlew publishAllPublicationsToStagingRepository`，再用 `-PsystemActionsRepository=<staging Maven 目录>` 验证；临时 HAR file 依赖只证明产物消费，不能代替 Registry 安装验收。

全变体 Maven 在 macOS 构建，按不可变标签上传 Release 归档，JitPack 下载并校验 SHA-256；发布配置见根目录 `jitpack-install.sh` / `release-checksums.txt`。HAR 和 Maven 分别版本化，不能从 Maven 版本推断 HAR 版本。

现有记录覆盖远程 Maven 编译、iOS Simulator Framework 链接，以及精确 OHPM Registry 版本安装与独立 `assembleHar`。真实拨号、商店、系统设置及 Kuikly 设备页面生命周期仍待验收。
