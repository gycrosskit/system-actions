# system-actions 功能与平台差异

本版 Native Module 源码：Maven / Git Pod `0.2.0-rc.7`。新增 `GYCWindowPolicy/Kuikly`，默认 Core / SPM 仍只包含窗口/观察源码。 Android/iOS 均提供真实 SDK receiver；iOS handler 由宿主已有 Shared framework 导出，Pod 不嵌入第二份 KMP framework/runtime。下表描述源码能力，发布及远程消费状态以对应 Release 为准；宿主接线与设备行为须单独验收。

历史发布记录（不含本次修复）：Maven / Swift Package / Git Pod 0.2.0-rc.6；HAR 0.2.0-rc.5（独立标签 native-0.2.0-rc.7）沿用原字节。源码基线：`f549e06fd4438da3c1a850c510cd2d6ab6956fee`，叠加本次修复；最终源码由不可变Git标签`0.2.0-rc.6`定位。构建、checksum及各渠道实际验收结果见[版本发布记录](https://github.com/gycrosskit/system-actions/releases/tag/0.2.0-rc.6)，源码/替身测试范围见本页验证表；不声明真实设备业务验收通过。

## 产物与职责

| 模块/产品 | 实际职责 |
|---|---|
| `system-actions-core` | SystemActions / ActionResult、Android/iOS系统动作与文件服务；A候选窗口lease/观察服务；JVM只有URL等规则无系统UI实现。 |
| `system-actions-kuikly` | Android/iOS/OHOS SystemActionsModule；公开动作、常亮、键盘/深色观察与dispose。Android导出真实receiver，iOS提供Shared导出handler与可选Pod receiver；宿主只注册工厂。 |
| `GYCWindowPolicy` | iOS14+ Swift Package/Git Pod；WindowPolicy、候选SystemObservations/FullscreenPolicyViewController；不是KMP core自动挂载的UI。 |
| `@gycrosskit/system-actions-native` | API22 HAR，SystemActions、GycSystemActionsModule、WindowPolicyController/SystemObservations。 |

构建边界：[core构建](../system-actions-core/build.gradle.kts)、[Kuikly构建](../system-actions-kuikly/build.gradle.kts)、[模块清单](../settings.gradle.kts)、[OHOS SDK配置](../ohos/build-profile.json5)。

除上表明确的 UI 入口外，本库没有独立 CMP 页面模块。Android/iOS 可由宿主原生适配把同一能力供 CMP 与 Kuikly 使用；“可注入两套UI”不代表库自动完成宿主接线、同名 Renderer 注册或品牌验收。

## 五入口功能矩阵

“原生实现，宿主注入”表示平台能力已有源码，CMP/Kuikly由宿主适配接入；“OHOS Module已实现”表示已有Kotlin/ArkTS调用链。矩阵说明功能接入边界，实际行为验证见下方验证范围。

| 功能/API组 | CMP Android | CMP iOS | Kuikly Android | Kuikly iOS | Kuikly OHOS |
|---|---|---|---|---|---|
| copyText / shareFile / dial / 外链 / app设置 | 原生实现，宿主注入 | 原生实现，宿主注入（分享需presenter） | Module实现，需宿主注册/验收 | Module实现，需宿主注册/验收 | OHOS Module已实现 |
| 全局定位设置 | 原生实现，宿主注入实现 | 不支持当前公开入口 | Module实现，需宿主注册/验收 | 不支持当前公开入口 | 不支持当前公开入口 |
| listingURL商店 / native商店 | 原生实现，宿主注入 / A商店 | 原生实现，宿主注入 URL / native不支持 | Module（URL/native），未验收 | Module（URL；native不支持），未验收 | URL / AppGallery |
| 常亮 | 原生实现，宿主注入 native | 原生实现，宿主注入 native | Module实现，需宿主注册/验收 | Module实现，需宿主注册/验收 | 常亮Module |
| 录屏隐私lease | 原生实现，宿主注入 native | 原生实现，宿主注入 native（遮罩差异） | 独立native lease，宿主接线 | 独立native lease，宿主接线（遮罩差异） | HAR lease |
| 键盘/深色观察（候选） | 需宿主接线/未验收 | 需宿主接线/未验收 | Module实现，需宿主注册/验收 | Module实现，需宿主注册/验收 | OHOS Module已实现 |
| 全屏（候选Android/iOS） | 需宿主接线/未验收 | 需显式VC接线/未验收 | 需宿主接线/未验收 | 需显式VC接线/未验收 | HAR lease/宿主接线 |

## 公开 API 组

- `SystemActions.copyText` / `shareFile(path,title)` / `dial` / `openExternalUrl` / `openAppSettings` / `openLocationSettings` / `openAppStore(listingUrl)` / `openNativeAppStore(applicationId)`。
- A `AndroidWindowPolicy.acquire` / `acquireFullscreen`、`AndroidSystemObservations.observeKeyboardHeight/observeDarkMode`；i `WindowPolicy` / `SystemObservations` / `FullscreenPolicyViewController.createFullscreenLease`。
- OHOS `WindowPolicyController.createLease/createFullscreenLease`和SystemObservations；`SystemActionsModule`提供动作、setKeepScreenOn、observe/stop与dispose，全屏为独立native lease接口。

## API 合同与差异分类

| 分类 | 具体输入 / OS / SDK边界 | 调用方应如何处理 |
|---|---|---|
| 组件接口缺口 | openLocationSettings：A Settings.ACTION_LOCATION_SOURCE_SETTINGS；i/O当前未建立可靠公开全局入口，Unavailable。 | app设置不等于全局定位开关；未用私有URI假成功。当前SDK核查不表示永久不可实现。 |
| 厂商限制 | iOS公开UIKit无法等价阻断系统静态截图；A FLAG_SECURE/O privacy可请求更强保护。 | i WindowPolicy仅捕获/镜像状态遮罩，不能承诺防截图；展示敏感内容前由宿主评估保护强度并确认设置。 |
| 厂商限制 | iOS14/15全屏带方向请求unsupported；16+requestGeometryUpdate只是受理，可能被Scene/多任务拒绝。 | 须使用FullscreenPolicyViewController并转发父容器/Info.plist方向和状态栏决策；safe-area布局仍由宿主约束，home indicator不能永久禁用手势。 |
| 宿主职责 | iOS shareFile默认服务没有presenter，返回Unavailable；A FileProvider；O只分享files/cache/temp普通文件。 | 提供当前presenter、Provider与受控文件；Requested只面板受理，不证明完成分享。复制文本允许空字符串且不读剪贴板。 |
| 厂商限制 | iOS openNativeAppStore(applicationId)不支持，需提供已核实listingURL；bundleId不能推导数字AppStoreID。 | A厂商商店/OAppGallery接受能力取决系统安装；商店/拨号/外链返回Requested都不是安装/通话/浏览完成。 |
| 宿主职责 | A观察dp、i当前View相交高度points、O vp；新Android/iOS native服务未替具体UI自动接线。 | 注册/stop/dispose由宿主生命周期负责，Scene/View变更i refresh；Module函数形式不代表三端Renderer齐备。 |
| 未验收 | 系统权限、外部应用动作、真实设备全屏/系统栏/键盘及宿主适配。 | 本轮未真实拨号、分享、商店跳转；系统受理/视觉验收和远程消费分别记录。 |

本版新增验证入口：Android/iOS Kuikly Maven 编译、共用handler协议/取消/替换/释放与真实SDK receiver 测试；iOS Pod源码及锁定OpenKuiklyIOSRender 2.28.0在Simulator arm64实际编译链接通过。测试实际执行结果及命令见[开发与验证](开发与验证.md#native-module-验证)。原始发布记录保留其版本范围，精确远程 Maven/Git Pod 以对应 Release 证据为准，宿主与设备行为需独立验收。
