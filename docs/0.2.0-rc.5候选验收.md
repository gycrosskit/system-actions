## 共同契约与原生配对

`copyText` / `shareFile` 进入既有 `SystemActions`，供 CMP Android/iOS 与 Kuikly Android/iOS/OHOS 使用。Android 复用 `AndroidFileActions`，须提供唯一 FileProvider authority；iOS 复用宿主持有的 `IosFileActions`，宿主提供当前 presenter 并管理其 close。缺少配置时分享返回 Unavailable，绝对本地路径格式不合法返回 InvalidInput；Requested 只表示系统受理，不表示用户完成分享。旧 Android Context 构造和 iOS 无参构造保留。

OHOS Kotlin Module 原 copy/share 只增加 override，既有 ArkTS HAR 源码未变，保留 HAR rc.4 / Render 2.28.0。Swift Package/Git Pod 保持 rc.2：当前 main 相比 rc.2 仅新增整行 API 注释；原始文件字节不同，去除整行注释和空行后生产代码逐字节相同，不声称整个文件与旧标签字节相同。

WindowPolicy 保持既有多 owner lease：Android close、Swift end、OHOS release。宿主复用已有 owner，退出时恢复原状态，不新增第二套 idle timer registry、共同 service close 或嵌套窗口 owner。iOS 录屏/镜像遮罩不能承诺禁止静态截图；iOS/OHOS 定位设置、iOS 原生商店等无公开系统入口仍明确 Unavailable。
