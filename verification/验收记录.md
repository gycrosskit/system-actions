# System Actions 0.1.1 本地验收

验收时间：2026-09-30。范围：system-actions Issues #2、#3。当前产物尚未执行 Git commit/push/tag、GitHub Release、JitPack 构建或 OHPM 发布。

## API 与边界

- Android `openLocationSettings()` 使用 ACTION_LOCATION_SOURCE_SETTINGS，沿用主线程、Application Context NEW_TASK 与启动返回后的受理结果。
- SystemActions 默认定位设置返回 Unavailable，保持旧自定义实现的源代码兼容；iOS 没有新增私有 URL，OHOS 显式返回 unavailable。
- `system-actions-kuikly` 只针对 ohosArm64；Android/iOS core 不依赖 Kuikly。OHOS core 只提供共用 API，输入校验仍由 HAR 实现。
- ArkTS GycSystemActionsModule 注入原生 SystemActions，同一实例可被宿主原生调用和 Renderer 共享；桥只分发，不复制号码或 URL 校验。
- Kotlin 每请求独立 ID，等待回执/最多 20 秒；取消和 dispose 清理 callback，await 返回后仍检查销毁状态。ArkTS 按请求 token 区分重用 ID，取消/销毁抑制迟到回调并清空引用。
