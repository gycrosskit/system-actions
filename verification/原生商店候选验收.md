# 原生商店候选验收

验收日期：2026-09-30。组件 Worktree `codex/native-store-component` 基于 c936992；宿主 `codex/component-extraction`。本轮未 commit/push/merge/tag/publish，前三项宿主改动保留。

## 版本与范围

已发布版本保持 Maven 0.1.2 / OHPM HAR 0.1.1。本地候选为 Maven 0.1.3 / HAR 0.1.2：`git ls-remote --tags origin 0.1.3 v0.1.3` 未找到标签，`ohpm info @gycrosskit/system-actions-native versions` 仅返回 0.1.0 / 0.1.1。当前候选不能从远程安装。

在既有 system-actions 增加 `openNativeAppStore(applicationId: String? = null)`，不创建第二个商店库。Android 使用当前包名或显式标识，规范化 manufacturer 后明确匹配固定商店，保留原宿主 URI 与 fallback 顺序；每次 Intent 限定包名，解析必须一致，实际启动成功才 Requested。查询由 AAR Manifest 合并。iOS 原生商店明确 Unavailable，宿主 HTTP(S) listingURL 保持原实现。

OHOS 使用当前 bundleName 或显式标识调用 AppGallery `loadProduct`，只以 onAppear 接受；异常、onError、显示前 onDisappear、20 秒无回执和取消返回 unavailable。原生 request handle 只完成一次并释放 resolver/timer。Renderer 通过既有 pending 对象 identity 过滤迟到事件，取消/销毁仅清理自身请求，其他原生 owner 的共享 SystemActions 继续可用。Kotlin 省略 null value，继续保持 timeout、dispose 及返回后的销毁检查。宿主仅委托组件，升级规则、本地化、窗口、主题、消息和任务仍由宿主持有。

## 失败与修正记录

首次 Android 异包 fixture 未提供 ApplicationInfo，Robolectric 按 Intent.package 补全，导致 Requested 的假失败。读取 ShadowApplicationPackageManager 源码后显式提供 resolvedPackage 的 ApplicationInfo，保留异包拒绝断言；生产逻辑未放宽，重跑通过。

独立 HAR 首次根目录 `ohpm install <HAR> --no-save --all` 仍为子模块查询未发布 0.1.2，返回 NOTFOUND。改为临时子模块 file 依赖完成安装和编译，finally 恢复精确候选版本；不算远程安装。宿主首次单独 `CompileArkTS` 命令未找到任务；随后标准 assembleHap 包含完整 CompileArkTS、NativeStrip 和打包链并通过，没有改业务或关闭缓存。

## 官方契约与未执行边界

[Huawei 展示应用详情页面](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/appgallery-productview-loadproduct)：loadProduct 返回 void，bundleName 必填，onAppear 表示详情页成功打开，onDisappear 表示关闭；该服务不支持模拟器。当前本机 HMS SDK `@hms.core.appgalleryservice.productViewManager.d.ts` 同步确认上述接口，只有 callback，没有取消/撤销 API。因此取消只终止组件等待，不承诺关闭 SDK 页面。

[Android 包可见性声明](https://developer.android.com/training/package-visibility/declaring)：固定查询包名可在 AAR Manifest 声明并由宿主合并。本组件只使用固定包名和当前宿主已有商店协议，不引入 QUERY_ALL_PACKAGES。

未执行 Android/iOS/OHOS 真机商店与真实 Kuikly 页面取消交互，没有设备安装、签名、Release 或业务通知。编译、mock 及 HAP 包内容不能替代设备验收。候选未远程发布，后续必须另行完成不可变 tag/Release/JitPack/OHPM 和精确远程消费。
